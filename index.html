连接设置

填写扣子「个人访问令牌（PAT）」，只需配置一次，保存在本机浏览器中。

获取方式：扣子 → 个人空间 → 扣子 API → 个人访问令牌。公开部署时建议用后端代理转发请求，避免令牌暴露在浏览器。

用于区分对话记录，可自定义；同一标识的历史消息在扣子侧可被智能体记住。

需已在扣子「发布 → 渠道 → Agent as API」中发布，否则接口会返回 4015。
